# VTBD - Variable Time Ball Drop
*Matt DiPalma, AMDG*

Not all time-delay alarms require the highest degree of precision. One common usage of an alarm is to wake its user up after a night of sleep, giving them enough time to get ready for work. For this simple purpose, it is not necessary for the alarm to sound at an atomically-precise moment. Instead, the +/- 10 minutes over 12 hours (+/- 1.4%) target precision of the time-delay alarm described in this RFP is potentially large enough to permit a narrow range of novel ideas. This proposal includes two interchangable concepts, each leveraging a fundamentally different phenomenon, but modular enough to use the same output indicator.
